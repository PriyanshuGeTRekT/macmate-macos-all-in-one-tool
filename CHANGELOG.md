# Changelog

## 1.0.0

First release.

- Battery percentage in the menu bar with per-app energy in watts and drain rate
- Window tiling with keyboard shortcuts, drag-to-edge snapping and an ⌥Tab window switcher
- Third-party mouse support: reverse scroll, smooth scrolling, button remapping, pointer options
- Keep awake for a set time or indefinitely
- System monitor: CPU, memory, network, GPU, storage, top processes
- App uninstaller that also removes leftover files, and a junk cleaner
- Clipboard history, screen text capture, color picker, microphone mute, keyboard cleaning lock,
  hold-⌘Q-to-quit, Finder cut and paste, display dimming and quick system toggles
