# Changelog

## 1.1.0

- Battery history: charge level over 24 hours or 7 days, and the apps that used the most energy
- Alerts when an app suddenly uses a lot of energy on battery
- Battery levels of AirPods, mice, keyboards and trackpads
- Sound tab with per-app volume, output and input device switching
- Hardware brightness for external monitors over DDC/CI, brightness keys for the display under the pointer
- Window thumbnails in the ⌥Tab switcher and window previews when hovering the Dock
- Caps Lock as a Hyper key and key remapping (Mouse & Keyboard tab)
- Calendar tab with the next meeting, Join buttons, alerts and an optional menu bar countdown
- Startup items manager, leftovers of deleted apps, and a large & old file finder
- Every global shortcut can be changed
- In-app updates, Homebrew cask, website, CI build check

## 1.0.0

First release.

- Battery percentage in the menu bar with per-app energy in watts and drain rate
- Window tiling with keyboard shortcuts, drag-to-edge snapping and an ⌥Tab window switcher
- Third-party mouse support: reverse scroll, smooth scrolling, button remapping, pointer options
- Keep awake for a set time or indefinitely
- System monitor: CPU, memory, network, GPU, storage, top processes
- App uninstaller that also removes leftover files, and a junk cleaner
- Clipboard history, screen text capture, color picker, microphone mute, keyboard cleaning lock,
  hold-⌘Q-to-quit, Finder cut and paste, display dimming and quick system toggles
